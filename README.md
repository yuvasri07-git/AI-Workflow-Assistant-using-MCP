### AI-Workflow-Assistant-using-MCP
Integrated Cursor AI with MCP servers and APIs to automate workflow tasks through prompt-based execution.

# Overview

This project demonstrates an AI-assisted email-to-LinkedIn workflow using the Model Context Protocol (MCP). As part of a NxtWave learning assessment, I connected an existing MCP server to Cursor, used prompts to process email content, and tested the workflow for creating or publishing a LinkedIn post.

# Objective

To gain hands-on experience integrating an AI client with external tools through MCP and using prompt engineering to support workflow automation.

# Tools and Technologies

- Cursor IDE — AI development environment and MCP client interface
- Model Context Protocol (MCP) — Protocol for connecting AI applications with external tools
- Existing MCP server — Provides the tools used by the workflow
- Prompt engineering — Instructing the AI to perform the required task
- Email and LinkedIn integrations — Used according to the configured server's available capabilities

# Workflow

1. Reviewed the NxtWave tutorial and assessment requirements.
2. Configured an existing MCP server for use in Cursor.
3. Connected the MCP server to the Cursor environment.
4. Used prompts to instruct the AI to read email content and prepare a relevant LinkedIn post.
5. Executed the workflow using the available MCP tools.
6. Tested the workflow and reviewed the resulting output.
